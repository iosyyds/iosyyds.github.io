## 部署到 GitHub Pages

1. 将本仓库所有文件推送到 GitHub 仓库
2. 确保仓库名为 `username.github.io`（username 为你的 GitHub 用户名）
3. 进入仓库 Settings → Pages
4. Source 选择 **Deploy from a branch**
5. Branch 选择 **main**，目录选择 **/(root)**
6. 点击 Save，等待几分钟后访问 `https://username.github.io`

> 注意：仓库根目录已包含 `.nojekyll` 文件，会跳过 Jekyll 构建，直接部署静态文件。

## Google AdSense 配置

1. 已在 `index.html` 中引入 AdSense 脚本，客户端 ID 为 `ca-pub-7156604582462189`
